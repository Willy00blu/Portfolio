Lecture transcriber

From a recorded lecture to a tidy note.

Role On my own, for the lectures I attend at the Politecnico·ongoing

The lecture transcriber is a program that takes the recording of a lecture I attend at Politecnico di Milano all the way to a tidy note in my vault, the archive of notes I keep in Obsidian. It transcribes the audio on the Mac, has Claude, Anthropic's artificial intelligence, write the note, matches the slides, captures the blackboard before it gets wiped and redraws the figures; then it logs the lecture and the tasks in Notion, a notes and database app. I use it every week.

Notes without listening to the lecture again

The way I use it, the pipeline isn't a way to skip lectures: in class you listen and try to understand, and the machine writes the note. Recordings come in from two places: lecture recordings, downloaded from WeBeep, and recordings from Pocket, the recorder described under Recommended apps, which connects directly to the pipeline through its MCP server (a channel through which other programs can read its recordings): on the app's Pocket page you choose which ones to bring in. Every evening at eight, an automatic run processes whatever is still waiting, if I haven't done it already, and prepares a document for each of the next day's lectures.

Time with and without the pipeline

The note and the uncertain points

Of the rules for the note, the one I care about most concerns the uncertain points: the question that takes the place of a gap is cleared up later with the slides or with a classmate.

The blackboard and the figures

The program finds the blackboard frame by looking at how much of the board is written on over time, ignoring the lecturer walking in front of it. The redrawn figures are plots, phase portraits (drawings of the trajectories of a dynamical system) and circuits; each course has an index of its figures, so a later lecture reuses the ones already made.

  • What you need to use it is explained below, in the transcriber package.
The package to download

The transcriber package

The package is the lecture transcriber in a downloadable version: the pipeline, which takes a recorded lecture all the way to a note in Obsidian, and its app.

  • Software: open source
  • Status: package in preparation
  • Requirements: Mac with an Apple chip (Apple Silicon), Claude subscription

What's in the package

The lecture recordings aren't included and won't be, because they are course material: everyone adds their own by hand, as the first chapter of the animation shows.

Requirements

  • System and hardware: macOS on Apple Silicon (arm64), required by mlx-whisper for transcription.
  • Software: Python and ffmpeg; optional OCR, with macOS's own or with tesseract.
  • Note writing: Claude Code, with a Claude subscription; alternatively gemini or ollama, both supported by the README.
  • Applications: Obsidian for the notes; Notion for the list of courses and activities used to classify each recording.

Costs

  • Transcription: local, on the Mac, at no cost.
  • Notes: Claude Code on the subscription, not the pay-as-you-go API; each lecture uses part of the subscription.
  • Usage: a system prompt of about 2,000 tokens; the review pass with the large model off by default.
